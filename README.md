# Smart Image Analyzer

Project completed in 2025 – documented here for portfolio purposes.

## Overview

This project consists of a desktop application developed in Python that uses the *YOLOv8* object detection model to analyze images through a modern graphical interface built with *CustomTkinter*.

It allows users to upload an image, detect objects, display confidence scores, count detected objects, and visualize the annotated image generated by *YOLO*.

## ✨ Features

- 📂 Upload an image from your computer
- 🤖 Detect objects using YOLOv8
- 📊 Count detected objects
- 📋 Sort detected objects by quantity
- 🎯 Display confidence score for each detection
- 🖼️ Display the annotated image with bounding boxes
- ⏱️ Display analysis time
- 🌍 English / French interface
- ⚠️ Basic error handling

## ⚙️ Installation

Clone the repository :

```bash
git clone https://github.com/yassinenajeh/python_smart_image_analyzer.git
```

Move into the project folder:

```bash
cd python_smart_image_analyzer
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

## 🧠 How it works

1. Select an image from your computer.
2. The application sends the image to the YOLOv8 model.
3. YOLO detects every object present in the image.
4. The detections are filtered using a confidence threshold.
5. The application displays :
   - detected objects;
   - confidence scores;
   - number of objects;
   - analysis time;
   - annotated image.
